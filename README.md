# 📊 Instagram Analysis Dashboard (2024–2025)
Project Overview

This project demonstrates the complete data analytics workflow using Power BI. The raw Instagram dataset was cleaned, transformed, and visualized into an interactive dashboard to analyze account performance, engagement, follower growth, impressions, and content categories.

The repository includes both the cleaned dataset and the Power BI dashboard so others can understand the complete analysis process.

# Objectives
- Clean and prepare raw Instagram data .
- Transform the dataset for analysis .
- Build an interactive Power BI dashboard .
- Analyze Instagram performance using KPIs .
- Identify trends in engagement and reach .

# Tools Used
- Microsoft Power BI 
- Microsoft Excel 
- Power Query 
- DAX 

# Data Preparation

The dataset was cleaned before visualization by performing:

- Removing duplicate records
- Handling missing values
- Correcting inconsistent data
- Formatting columns
- Transforming data using Power Query
- Creating calculated measures using DAX

# Dashboard Features

The dashboard provides insights into:

# 📌 KPI Cards

- Total Engagement
- Followers Gained

# Key Insights
 - Creator accounts generated significantly higher impressions than brand accounts.
 - Viral content achieved the highest average reach.
 - Reels and carousel posts contributed strongly to engagement.
 - Monthly follower growth remained relatively stable with noticeable peaks in specific months.
 - Different content categories showed varying levels of audience reach.
