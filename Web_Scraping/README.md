# A Python web scraping project that extracts hospital information from Wikipedia using Requests and BeautifulSoup, cleans the data with Pandas, and exports it to a CSV file for further analysis.

🏥 Hospital Data Web Scraping using Python

This project demonstrates how to scrape structured data from a Wikipedia page using Python. It collects information about hospitals in India, processes the HTML table, and converts the extracted data into a clean Pandas DataFrame, which is then exported as a CSV file for analysis.

🚀 Features
- Scrapes hospital data directly from Wikipedia.
- Uses Requests to fetch webpage content.
- Parses HTML using BeautifulSoup.
- Extracts structured table data (Hospital Name, Type, Managed By, and Location).
- Stores data in a Pandas DataFrame.
- Exports the final dataset to a CSV file.
- Demonstrates an end-to-end web scraping workflow.

🛠️ Technologies Used
- Python
- Requests
- BeautifulSoup (bs4)
- Pandas
- Jupyter Notebook
  
📂 Dataset
- Source: Wikipedia – List of Hospitals in India
- Output: CSV file containing hospital details

📊 Data Extracted
- Hospital Name
- Hospital Type
- Managed By
- Location
  
📈 Learning Outcomes
- Sending HTTP requests using the Requests library.
- Parsing HTML documents with BeautifulSoup.
- Extracting and cleaning tabular data. 
- Working with Pandas DataFrames.
- Exporting structured data to CSV for further analysis.
